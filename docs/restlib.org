* API
:PROPERTIES:
:CUSTOM_ID: api
:END:
#+CINDEX: API
#+VINDEX: restlib

To use *restlib*, include it in your code using the ~require~ function:

#+begin_src elisp :lexical no
  (require 'restlib)
#+end_src


The *restlib* library is organized into sections listed below:


** Network
#+VINDEX: restlib-fetch-json

Network-related functions.

- Function: restlib-fetch-json URL ::
  - URL: string or URL object

  Synchronous fetch URL that provides a JSON response.

  The result is the JSON response deserialized into a `hash-table', with JSON ~null~ values converted to ~nil~.

** URL Components
#+VINDEX: restlib-url-parse
#+VINDEX: restlib-url-filename
#+VINDEX: restlib-url-path
#+VINDEX: restlib-url-query
#+VINDEX: restlib-url-query-items
#+VINDEX: restlib-url-add-query-items
#+VINDEX: restlib-url-remove-query


URL-related functions. For more information on URL objects refer to the [[info:url#Top][URL manual]].

- Function: restlib-url-parse URL ::
    - URL: string

  Convenience function to return a parsed object given URL string.

- Function: restlib-url-filename URL ::
    - URL: string or URL object

  Get URL filename.

  Extract filename via ~url-filename~.

- Function: restlib-url-path URL ::
  - URL: string or URL object

  Get URL path.

  Extract only path from URL, omitting query parameters and fragment.

- Function: restlib-url-query URL ::
  - URL: string or URL object

  Get URL query.

  Extract query as string from URL.

- Function: restlib-url-query-items URL ::
  - URL: string or URL object

  Extract query items from URL.

  Extract query items using ~url-parse-query-string~.

- Function: restlib-url-add-query-items URL ITEMS &optional OBJ-RESULT ::
  - URL: string or URL object
  - ITEMS: list of lists as specified for ~url-build-query-string~
  - OBJ-RESULT: if non-nil then return URL object, else string

  Add query ITEMS to URL.

  If URL has an existing query fragment, then ITEMS will be naively appended to it, with no regard for duplicate keys.

- Function: restlib-url-remove-query URL &optional OBJ-RESULT ::
  - URL: string or URL object
  - OBJ-RESULT: if non-nil then return URL object

  Remove query from URL.

** JSON
#+VINDEX: restlib-json-empty-string-to-nil

JSON-related functions. For more information on JSON objects, refer to the [[info:elisp#Parsing JSON][Parsing JSON section of the Elisp manual]].

- restlib-json-empty-string-to-nil OBJ KEY ::
  - OBJ: map-type object (typically a ~hash-table~)
  - KEY: key

  Convert empty string value for KEY to nil in OBJ.
